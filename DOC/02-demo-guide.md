# 02. 데모 가이드

데모는 하나의 HTML 안에서 6개 뷰를 전환하는 구조입니다. 상단 내비게이션 또는 해시(`#app`, `#editor`, `#grid`, `#tree`, `#layout`, `#skin`)로 이동합니다.

## 1. 실행 방법

### 1.1 서버로 실행 (권장)

```bash
npm start
```

- 데모: `http://localhost:4173/`
- 문서: `http://localhost:4173/DOC/`
- 포트 변경: `PORT=8080 npm start`
- API 지연: `API_DELAY=800 npm start` (기본 220ms)
- 바인딩 호스트: `HOST=127.0.0.1 npm start`

서버는 정적 파일과 다음 API 를 함께 제공합니다.

| 메서드 | 경로 | 응답 |
| --- | --- | --- |
| GET | `/api/menu` | 메뉴 JSON |
| GET | `/api/layers/:id` | 레이어 JSON |
| GET | `/api/data/:id` | 데이터 JSON |
| GET | `/api/tree` | 트리 JSON |
| POST | `/api/submit` | 저장 모의 응답 |
| POST | `/api/action/:name` | 액션 모의 응답 |

### 1.2 파일로 직접 열기

`index.html` 을 더블클릭해 `file://` 로 열어도 됩니다. ES 모듈은 `file://` 에서 동작하지만 `fetch('/api/...')` 는 실패합니다. 이때 `demo.js` 가 등록한 mock 이 **자동 폴백**으로 사용됩니다.

상단의 `MOCK↺ fallback` 배지는 mock 폴백이 준비되어 있음을 나타냅니다. 실제 요청이 성공하면 서버 응답을, 실패하면 mock 응답을 사용합니다.

## 2. 6개 데모 뷰

### 2.1 통합 앱 (`#app`)

메뉴 JSON → 레이어 JSON → 데이터 JSON 순서로 AJAX 로드하는 전체 앱입니다.

- 메뉴: 대시보드, 주문 입력, 결재 문서, 조직도, 설정(일반/스킨)
- 탭: 메뉴를 열면 탭이 생기고 닫을 수 있습니다.
- 새로고침: 현재 탭의 레이어와 데이터를 다시 읽습니다.
- 로그: AJAX 요청 이력(상태, 소요 시간, mock 여부)을 확인합니다.
- 스킨 패널: 왼쪽 사이드바 하단에서 테마/모양/밀도를 바꿉니다.

확인할 화면:

| 메뉴 | 확인 내용 |
| --- | --- |
| 대시보드 | HTML KPI, JSON 임베드 그리드(고정 열/필터/가상 스크롤), 조직도 트리 |
| 주문 입력 | 12컬럼 폼, 조건부 필드(긴급 사유), 필수/패턴/이메일 검증, JSON/초기화/저장 액션 |
| 결재 문서 | 에디터 임베드, 읽기 전용 필드, 결재선 트리, 제출 |
| 조직도 | `data: false` 메뉴로 데이터 요청 생략, 트리 레이어만 로드 |
| 일반 설정 | 스위치/선택/숫자 등 컨트롤 조합과 저장 |
| 스킨 갤러리 | 버튼 액션으로 테마/모양/밀도/테두리 변경 |

### 2.2 에디터 (`#editor`)

- 서식, 문단, 글자 크기, 색상, 정렬, 목록, 링크
- 표 삽입 후 셀 내부에서 표 도구 표시
- 이미지 파일 선택, 붙여넣기, 드래그 앤 드롭
- HTML 소스 보기, 전체화면, 수동 저장, 자동저장
- API 버튼: HTML/텍스트/데이터 조회, 이미지 삽입, 읽기 전용 전환

### 2.3 그리드 (`#grid`)

- 500행 가상 스크롤 데이터
- `+ 1,000행`, 정렬, 열 고정/해제, 검증, 변경 내역, CSV, 특정 행 이동
- 셀 편집 시 `change` 이벤트 로그
- 행 선택 시 선택 개수 로그

### 2.4 트리 (`#tree`)

- 조직도 트리, 트라이스테이트 체크
- 검색과 하이라이트
- 전체 펼침/접힘, 체크 초기화, 체크 목록 로그
- 노드 선택과 키보드 탐색

### 2.5 레이아웃 (`#layout`)

- flow 배치와 absolute 배치 예제
- 조건부 표시, 검증, 값 수집, 제출
- 에디터/그리드/트리 임베드
- 사용자 정의 컨트롤

### 2.6 스킨 (`#skin`)

- 10개 테마 스와치
- 4개 모양 프리셋, 모서리 슬라이더, 테두리 토글
- 3개 밀도
- 현재 스킨 상태 로그, 초기화

## 3. 데이터 수정과 재생성

데모 데이터의 단일 소스는 `src/data/seed.js` 입니다. `menu.json`, `layers/*.json`, `data/*.json`, `tree.json` 은 생성 파일입니다.

```bash
# seed.js 수정 후
npm run build:data
```

서버가 실행 중이어도 JSON 파일을 매 요청마다 읽으므로 새로고침하면 반영됩니다. 파일을 직접 수정했다면 다음 `build:data` 실행 때 덮어써집니다.

## 4. 문서 뷰어

`DOC/index.html` 은 `DOC/docs-data.js` 를 일반 스크립트로 읽어 Markdown 을 렌더링합니다. 외부 CDN 이 없고 `file://` 에서도 동작합니다.

```bash
npm run build:docs
```

`DOC/*.md` 를 추가/수정한 뒤 위 명령을 실행해야 뷰어 목록과 본문이 갱신됩니다.

뷰어 기능:

- 파일명 기반 id(`#10-api-reference`) 해시 라우팅과 헤딩 anchor
- 제목/본문 검색, 코드 블록 복사, 이전/다음 문서 이동
- 라이트/다크 테마 전환과 localStorage 저장
- 모바일 오프캔버스 목록
- Markdown 링크(`02-demo-guide.md`)를 뷰어 경로로 자동 변환

## 5. 점검 명령

```bash
npm run check
```

검사 항목:

1. 11개 ES 모듈 import 성공
2. `webui.js` 전역 내보내기와 버전 일치
3. 컨트롤 20종 이상, 테마 10종
4. seed.js 메뉴/레이어/데이터 정합성
5. 생성된 JSON 파싱
6. DOC Markdown 과 `docs-data.json` 동기화

브라우저 실제 실행 점검은 Edge CDP 스크립트로 수행했습니다.

```bash
node tools/browser-check.mjs
```

이 스크립트는 Edge 를 헤드리스로 띄워 앱 메뉴/탭/그리드/트리/AJAX, 주문 폼 검증, 에디터, 조직도, 스킨, 5개 데모 뷰, 모바일 사이드바를 확인하고 콘솔 오류를 수집합니다. 로딩 오버레이처럼 `hidden` 속성으로 숨긴 요소가 화면에 남지 않는지도 함께 검사합니다. 환경에 Edge 경로가 다르면 스크립트 상단의 경로를 조정해야 합니다.

## 6. 문제 해결

| 증상 | 원인/해결 |
| --- | --- |
| 화면이 비어 있음 | `file://` 로 열었고 mock 도 없는 경우. `npm start` 사용 또는 `demo.js` mock 확인 |
| 데이터가 예전 값 | `src/data/seed.js` 만 수정한 경우. `npm run build:data` 실행 |
| API 404 | 레이어/데이터 id 와 `menu.json` 의 id 일치 여부 확인 |
| 포트 충돌 | `PORT=8081 npm start` |
| 문서 목록이 비어 있음 | `npm run build:docs` 미실행. `DOC/docs-data.js` 생성 여부 확인 |
| 스킨이 일부만 적용됨 | `skin.init({ target })` 또는 `createApp` 사용 여부 확인. `data-wui-*` 속성이 대상 요소에 있어야 함 |
| 한글 JSON 깨짐 | 파일을 UTF-8 로 저장. 서버는 `charset=utf-8` 로 응답 |
